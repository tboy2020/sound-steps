# Sound Steps 🦉

Voice-first **phonics for little ones (~3 yrs)** — learn the SOUND of each letter, then build words from **syllable blocks** (tap *um · brel · la*, blend slow→fast). Single-file, installable PWA, works offline. Cornerstone Studio · *Glory to God alone · AMHG*.

Built on the proven **sound → syllable** method (master letter sounds first, then blend chunks into words — e.g. *e·du·ca·tor*).

## What's inside
- **Letter Sounds** — explore letters in teaching order (s, a, t, i, p, n … continuous sounds before stops), each with its sound + a picture; tap to hear. Plus a "tap the one that says /sss/" sound game.
- **Build a Word** — the signature syllable builder: tap each sound block left-to-right (it speaks), then it blends slow→fast into the whole word. Starts with CVC words (cat, sun) and ramps up to 3–4 syllables.
- **Stickers** — a reward collection.
- **Grown-ups:** tap ⚙️ (code **2020**) for progress, a voice on/off toggle, and reset.

Audio-first with big tap targets so a pre-reader can use it alone. Single `index.html` (ES5) + `manifest.json` + `sw.js` + `icon.svg`. Progress saved in `localStorage`; voice via the browser's SpeechSynthesis.

## Run / deploy
Open `index.html`, or serve the folder and visit it. For GitHub Pages: push to a public repo and enable Pages (`main`, root).
